糯糯鍵盤｜下載與安裝

糯糯鍵盤

軟軟的按鍵，記住你的每一句。

原「星星鍵盤」・下載與安裝說明

自己做的手機鍵盤：注音（不打聲調也能出字）、拼音、手寫、英文、韓文、日文、表符、顏文字、花式文字、快捷片語、剪貼簿、翻譯、可愛主題和自己的背景照片。還沒上架商店，照下面的步驟自己安裝。

iPhone 沒上架的 App 要用電腦裝，第一次大約 15 分鐘。用免費 Apple ID 裝的 App 每 7 天要用電腦重裝一次（資料不會不見）。

先準備

iPhoneiOS 15 以上
傳輸線能接電腦的線（充電線不一定能傳資料）
電腦Windows 或 Mac
Apple ID免費的就可以

安裝工具會要你輸入 Apple ID 和密碼（它要用你的帳號幫 App 簽名）。不放心的話，可以另外註冊一個專門裝 App 用的 Apple ID。

下載安裝檔（在電腦上）

下載 iPhone 安裝檔 已發布：第 27 版 更新內容

安裝檔會直接下載到電腦。這裡只提供已完成打包的版本；新版完成後重新開啟此頁即可。舊版 App 名稱可能仍顯示「星星鍵盤」。

用電腦裝進 iPhone

  1. 安裝 iTunes：要從 Apple 官網下載的 Windows 版，不要用 Microsoft Store 的版本。
    apple.com/itunes/download/win64
  2. 安裝 Sideloadly：到 sideloadly.io 下載 Windows 版並安裝。
    如果 Sideloadly 說還缺 iCloud，照它畫面上的連結裝非 Store 版的 iCloud。
  3. 用傳輸線把 iPhone 接到電腦，解鎖手機。手機跳出「要信任這部電腦嗎？」時按信任，再輸入手機密碼。
  4. 打開 Sideloadly：
    • 把 StarKeyboard.ipa 拖到左上角的方框（或按方框選檔案）
    • 「iDevice」選你的 iPhone
    • 「Apple account」填你的 Apple ID
    • 按 Start，輸入 Apple ID 密碼；有兩步驟驗證就輸入手機收到的驗證碼
  5. 等下面的進度跑完、出現 Done 就裝好了，接著做下面的「iPhone 上的設定」。
  1. Mac 不用裝 iTunes。到 sideloadly.io 下載 Sideloadly 的 macOS 版，拖進「應用程式」。
  2. 第一次打開如果說「無法打開」：到 系統設定 › 隱私權與安全性，往下找到 Sideloadly，按強制打開（或「仍要打開」）。
  3. 用傳輸線把 iPhone 接到 Mac，解鎖手機，手機跳出「要信任這部電腦嗎？」時按信任。Mac 若問「允許配件連接」也按允許。
  4. 打開 Sideloadly：
    • 把 StarKeyboard.ipa 拖到左上角的方框
    • 「iDevice」選你的 iPhone
    • 「Apple account」填你的 Apple ID
    • 按 Start，輸入 Apple ID 密碼；有兩步驟驗證就輸入驗證碼
  5. 等下面出現 Done 就裝好了，接著做下面的「iPhone 上的設定」。

iPhone 上的設定（只要做一次）

  1. 打開開發者模式：設定 › 隱私權與安全性 › 開發者模式，打開後手機會重新開機，開機後再按一次「開啟」並輸入密碼。
    要先用 Sideloadly 裝好 App，這個選項才會出現。
  2. 信任開發者：設定 › 一般 › VPN 與裝置管理，點你的 Apple ID（開發者 App 下面那一個），按「信任」。
  3. 加入鍵盤：設定 › 一般 › 鍵盤 › 鍵盤 › 新增鍵盤…，往下找到「第三方鍵盤」，選糯糯鍵盤。
  4. 允許完整取用：回到鍵盤清單點「糯糯鍵盤」，打開「允許完整取用」，跳出提醒時按「允許」。
    剪貼簿紀錄、按鍵聲音、震動、貼圖、背景照片、翻譯、檢查新版都需要它。
  5. 開始打字：到任何能打字的地方（LINE、備忘錄都可以），按住左下角的 🌐 地球鍵，在跳出的清單選「糯糯鍵盤」。之後按一下地球鍵就能在鍵盤之間切換。
  6. 想看說明或試打，打開桌面上的「糯糯鍵盤」App。

放自己的背景照片（iPhone）

  1. 打開「照片」App，點開想用的照片，按左下角的分享 › 拷貝。
  2. 叫出糯糯鍵盤，按上面工具列的 ⚙ 設定 › 背景照片 › 從剪貼簿貼上圖片。
  3. 鍵盤會直接進入調整：一指拖拉移動照片、兩指捏合放大縮小，看到的就是之後的樣子。調好按完成。
  4. 之後想再調：⚙ 設定 › 調整照片位置和大小。「照片淡化」和「按鍵透明度」可以讓字更清楚。
  5. 可以放好幾張：再拷貝別張照片，按「＋ 從剪貼簿新增照片」。設定裡點縮圖換照片，也可以選固定這張、每次打開換、每天換。每張照片的位置和大小各自記住。

每 7 天重裝、裝新版

免費 Apple ID 裝的 App 只能用 7 天，到期時鍵盤會叫不出來、App 一打開就閃退。這時候照上面「用電腦裝進 iPhone」再裝一次就好，不用刪掉舊的，設定、照片、剪貼簿紀錄、自製表符都會保留。

有新版時鍵盤上方會提醒你。裝新版也是一樣的步驟：到下載頁拿最新的 StarKeyboard.ipa，用 Sideloadly 直接裝，會蓋過舊版。重裝會重新算 7 天，所以順便更新最划算。

開發者模式和「信任」通常只要設定一次。如果重裝後又打不開，再去「VPN 與裝置管理」按一次信任。

Android 不用電腦，用手機直接下載安裝，大約 5 分鐘，也不用每 7 天重裝。

先準備

Android 手機Android 8 以上
空間約 150 MB
網路安裝檔約 70 MB，建議連 Wi-Fi

已經裝過舊版？先移除

目前的測試版每一版的簽名都不一樣，不能直接蓋過舊版，會顯示「未安裝應用程式」或「套件與現有套件衝突」。請先移除舊版：長按桌面上的「糯糯鍵盤」圖示 › 解除安裝（或 設定 › 應用程式 › 糯糯鍵盤 › 解除安裝）。移除後設定和背景照片會不見，裝好要重新設定。

第一次安裝的人跳過這一步。

下載並安裝

下載 Android 安裝檔 已發布：第 26 版 更新內容 本頁會自動取得最新已發布版本；新版打包完成後，重新開啟此頁即可。各版本的更新內容在 所有版本（名稱有「Android 第幾版」的）。
  1. 用 Android 手機打開這一頁，按上面的「下載 Android 安裝檔」。瀏覽器如果問「要下載嗎？」或說「這類檔案可能有害」，按下載／仍要下載。
  2. 下載好後，點通知列上的 StarKeyboard.apk。找不到的話，打開「檔案」（或「我的檔案」）App › 下載資料夾，點那個檔案。
  3. 第一次會說「基於安全考量，你的手機目前不允許安裝這個來源的應用程式」：按設定，打開「允許來自這個來源的應用程式」，再按返回。
  4. 按安裝。跳出 Play 安全防護的提醒時，按「仍要安裝」，有時要先按「更多詳細資料」才看得到。因為這個 App 沒有上架 Google Play，所以會有這個提醒。
  5. 裝好按開啟，接著做下面的「打開鍵盤」。
小米、紅米、POCO 的手機

可能會先跑「安全性檢查」或要等幾秒、勾選「我已了解風險」才能按安裝，照畫面按繼續安裝就好。

如果完全不讓你裝，到 設定 › 隱私保護 › 特殊權限設定 › 安裝未知應用，讓你用來下載的瀏覽器或「檔案管理」可以安裝。

打開鍵盤（只要做一次）

  1. 打開「糯糯鍵盤」App，按 ① 打開鍵盤設定。
  2. 在跳出來的清單裡，把糯糯鍵盤的開關打開。手機會提醒「這個輸入法可能會收集你輸入的所有文字」，按確定。
    每一個第三方鍵盤都會跳這個提醒。糯糯鍵盤只把你的設定、剪貼簿紀錄存在你自己的手機裡。
  3. 按返回回到 App，按 ② 切換成糯糯鍵盤，在清單裡點「糯糯鍵盤」。
  4. 在 App 下面的試打框打幾個字，看到糯糯鍵盤就完成了。

放自己的背景照片（Android）

  1. 打開「糯糯鍵盤」App，按新增一張背景照片，選照片。
  2. 選好後鍵盤會自動跳出來並進入調整：一指拖拉移動照片、兩指捏合放大縮小，看到的就是之後的樣子。調好按完成。
    有找到臉的話，照片會先自動對準臉。
  3. 之後想再調：鍵盤的 ⚙ 設定 › 調整照片位置和大小。「照片淡化」和「按鍵透明度」可以讓字更清楚。
  4. 可以放好幾張：在 App 再按一次「新增一張背景照片」。鍵盤設定裡點縮圖換照片，也可以選固定這張、每次打開換、每天換。每張照片的位置和大小各自記住。

裝新版

有新版時，打開「糯糯鍵盤」App 最上面會出現「有新版」和下載按鈕；或直接按這一頁的「下載 Android 安裝檔」。

  1. 先下載新的安裝檔（還不要點開）。
  2. 移除舊版：長按「糯糯鍵盤」圖示 › 解除安裝。
  3. 到「檔案」App 的下載資料夾點新的 StarKeyboard.apk 安裝。資料夾裡有好幾個檔案的話，點最新的那個。
  4. 重新做一次「打開鍵盤」的 ① ②，背景照片要重新挑。

等正式簽名設定好以後，就可以直接蓋過舊版、不用重新設定，到時候這裡會改寫。

怎麼用

iPhone 和 Android 的功能一樣。工具列在鍵盤最上面那一排；⚙ 是鍵盤設定。

注音：不打聲調也可以

打到一半上面就會先出字。可以只打每個字開頭的注音，連打好幾個字再一起選：ㄨㄛㄏㄓㄜㄧ → 我會這樣、ㄋㄏ → 你好。打聲調也可以，會更準。

拼音（給習慣拼音的朋友）

到 ⚙ › 輸入法 打開「拼音」，按 中／英 切過去。打 nihao 或只打聲母 nh 都會出「你好」。預設是繁體字，想要簡體在設定裡打開「拼音輸出簡體字」。

𝒜 花式文字

按工具列的 𝒜，打字後按「變花樣」，點一個樣式送出。對方也看得到：𝓼𝓽𝓪𝓻、ⓢⓣⓐⓡ、刪̶除̶線̶、♡ 愛心 ♡。英文的樣式最多。

快捷片語

⚙ › 快捷片語 › ＋ 新增：先打整段話（例如地址），再打縮寫（例如「地址」或 addr）。之後打縮寫，候選字第二個就是整段話。

英文滑行輸入

英文鍵盤上手指不要放開，依序滑過字母再放開，就會打出整個字，例如滑過 h→e→l→o 出 hello。認錯了就點上面列出的別的字。不想用可以在 ⚙ › 打錯字修正 關掉。

字體、主題、特效、按鍵音

⚙ 裡可以換主題顏色、按鍵造型（圓角、果凍、貓耳、雲朵、兔兔、狗狗、布丁、水母、火焰、水滴、鴨鴨）、字體（粉圓、芫荽、文楷）、按鍵特效（按下去冒出星星、愛心、花花…），還有可愛按鍵音（iPhone：系統聲、柔和叮叮；Android：泡泡、木琴、叮鈴、啵啵）。字體只改變你鍵盤上的樣子。

剪貼簿、表符、翻譯、手寫

剪貼 會記住你複製過的文字，可以釘選。☺ 表情、(•ᴗ•) 顏文字、譯 先打中文再翻成外文、✍ 用手指寫字。

常見問題

iPhone：App 一打開就閃退，或說「無法驗證 App」
還沒開開發者模式，或還沒在「VPN 與裝置管理」按信任。裝超過 7 天也會這樣，用電腦重裝一次就好。
iPhone：Sideloadly 找不到手機
換一條線或換一個 USB 孔，手機保持解鎖，重新按一次「信任」。Windows 可以先打開 iTunes，看看有沒有出現手機。
iPhone：Sideloadly 說 App ID 數量到上限
免費帳號 7 天內最多建立 10 個 App ID。等幾天，或改用另一個 Apple ID。
iPhone：鍵盤清單裡找不到糯糯鍵盤
先打開一次「糯糯鍵盤」App，再把手機重新開機。
iPhone：打密碼的時候變回原本的鍵盤
這是 iOS 的規定，所有第三方鍵盤在密碼欄都會被換掉，不是壞掉。
Android：顯示「未安裝應用程式」
手機裡還有舊版。先長按圖示解除安裝，再點新的安裝檔。
Android：鍵盤突然叫不出來、變回原本的鍵盤
鍵盤當掉或清除過資料時，手機會自動換回內建鍵盤。打開「糯糯鍵盤」App 再按一次 ① ②。如果 App 最上面出現「⚠️ 鍵盤出過問題」，按「複製紀錄」傳給把這頁給你的人。
剪貼簿沒有記到
iPhone 要打開「允許完整取用」，而且只會在鍵盤打開的時候記，所以是複製完、切到要打字的地方時才記錄。Android 是糯糯鍵盤是目前的鍵盤時才會記。
注音一直跳出奇怪的字
點正確的候選字，鍵盤會記住你常選的字，越用越順。也可以多打一點注音或打聲調，會更準。
