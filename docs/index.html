★ 星星鍵盤安裝說明

自製的 iPhone 鍵盤：注音、手寫、英文、韓文、日文、表符、顏文字、剪貼簿紀錄、翻譯、可愛主題。還沒上架 App Store，要用電腦裝進 iPhone，大約 15 分鐘。

用 Android 手機的話不用電腦，直接跳到 Android 手機安裝。下面「先準備」到「每 7 天要重裝一次」是 iPhone 的步驟。

先準備（iPhone）

iPhoneiOS 16 以上
傳輸線能接電腦的線
電腦Windows 或 Mac
Apple ID免費的就可以

安裝工具會要你輸入 Apple ID 和密碼（它要用你的帳號幫 App 簽名）。不放心的話，可以另外註冊一個專門裝 App 用的 Apple ID。

下載安裝檔

前往下載頁 在 Assets 下面點 StarKeyboard.ipa，存到電腦上

用電腦裝進 iPhone

  1. 安裝 iTunes：要從 Apple 官網下載的 Windows 版，不要用 Microsoft Store 的版本。
    apple.com/itunes/download/win64
  2. 安裝 Sideloadly：到 sideloadly.io 下載 Windows 版並安裝。
    如果 Sideloadly 說還缺 iCloud，照它畫面上的連結裝非 Store 版的 iCloud。
  3. 用傳輸線把 iPhone 接到電腦，解鎖手機，手機跳出「要信任這部電腦嗎？」時按信任並輸入手機密碼。
  4. 打開 Sideloadly：
    • 把 StarKeyboard.ipa 拖到左上角的方框
    • 「iDevice」選你的 iPhone
    • 「Apple account」填你的 Apple ID
    • 按 Start，輸入 Apple ID 密碼；有兩步驟驗證就輸入手機收到的驗證碼
  5. 等下面出現 Done 就裝好了，接著做下面的 iPhone 設定。
  1. Mac 不用裝 iTunes。到 sideloadly.io 下載 Sideloadly 的 macOS 版，拖進「應用程式」。
  2. 第一次打開如果說「無法打開」：到 系統設定 › 隱私權與安全性，往下找到 Sideloadly，按強制打開（或「仍要打開」）。
  3. 用傳輸線把 iPhone 接到 Mac，解鎖手機，手機跳出「要信任這部電腦嗎？」時按信任。Mac 若問「允許配件連接」也按允許。
  4. 打開 Sideloadly：
    • 把 StarKeyboard.ipa 拖到左上角的方框
    • 「iDevice」選你的 iPhone
    • 「Apple account」填你的 Apple ID
    • 按 Start，輸入 Apple ID 密碼；有兩步驟驗證就輸入驗證碼
  5. 等下面出現 Done 就裝好了，接著做下面的 iPhone 設定。

iPhone 上的設定

  1. 打開開發者模式：設定 › 隱私權與安全性 › 開發者模式 打開，手機會重新開機，開機後再按一次「開啟」。
    要先用 Sideloadly 裝好 App，這個選項才會出現。
  2. 信任開發者：設定 › 一般 › VPN 與裝置管理，點你的 Apple ID，按「信任」。
  3. 加入鍵盤：設定 › 一般 › 鍵盤 › 鍵盤 › 新增鍵盤…，在「第三方鍵盤」選星星鍵盤。
  4. 允許完整取用：在同一頁點「星星鍵盤」，打開「允許完整取用」。剪貼簿、聲音、震動、貼圖、背景照片、翻譯都需要它。
  5. 開始打字：在任何輸入框按住 🌐 地球鍵，選「星星鍵盤」。也可以打開桌面上的「星星鍵盤」App，看說明和試打。

每 7 天要重裝一次

免費 Apple ID 裝的 App 只能用 7 天，到期時打開會閃退。再照上面的步驟用 Sideloadly 裝一次就好，設定、剪貼簿紀錄、自製表符都不會不見。

Android 手機安裝（不用電腦）

下載 Android 安裝檔 約 70MB，建議連 Wi-Fi
  1. 用 Android 手機打開這一頁，按上面的「下載 Android 安裝檔」。瀏覽器如果問「要下載嗎？」或說「這類檔案可能有害」，按下載／仍要下載。
  2. 下載完按通知列上的檔案（或到「檔案」App 的「下載」資料夾找 StarKeyboard.apk）點開。
  3. 第一次會說「基於安全考量，你的手機目前不允許安裝這個來源的應用程式」：按設定，打開「允許來自這個來源的應用程式」，再按返回。
  4. 按安裝。如果跳出 Play 安全防護的提醒，按「仍要安裝」或「更多詳細資料 › 仍要安裝」（因為這個 App 沒有上架 Google Play）。
  5. 打開「星星鍵盤」App，照畫面上的 ① ② 按鈕：先在清單裡打開星星鍵盤，再切換成星星鍵盤，然後在下面試打。

Android 版不用每 7 天重裝。之後有新版，打開「星星鍵盤」App 會出現「有新版」和下載按鈕。目前測試版更新時要先移除舊版再裝（正式版會改成可以直接更新）。

常見問題

打開 App 馬上閃退，或說「無法驗證 App」
還沒開開發者模式，或還沒在「VPN 與裝置管理」按信任。裝超過 7 天也會這樣，重裝即可。
Sideloadly 找不到我的 iPhone
換一條線或換一個 USB 孔，手機保持解鎖，重新按一次「信任」。Windows 可以先打開 iTunes，看看有沒有出現手機。
Sideloadly 說 App ID 數量到上限
免費帳號 7 天內最多建立 10 個 App ID。等幾天，或改用另一個 Apple ID。
鍵盤清單裡找不到星星鍵盤
先打開一次「星星鍵盤」App，再把手機重新開機。
打密碼的時候變回原本的鍵盤
這是 iOS 的規定，所有第三方鍵盤在密碼欄都會被換掉，不是壞掉。
剪貼簿沒有記到
要打開「允許完整取用」。iOS 只讓鍵盤在打開的時候讀剪貼簿，所以是複製完、切到要打字的地方時才記錄。
