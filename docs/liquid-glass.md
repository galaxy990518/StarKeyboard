# 原生液態玻璃驗證

## 啟用條件

- 使用 Xcode 26 SDK 編譯，裝到 iOS 26 以上的 iPhone。
- 「按鍵質感」選 **液態玻璃**，「按鍵造型」選 **圓角** 或 **果凍**。
- 圓角／果凍的字母鍵、功能鍵、空白鍵，以及工具列／候選字列使用 `UIGlassEffect`。沒有背景照片也可使用。
- 其他造型保留既有的路徑繪製；iOS 15–18 或舊版編譯器保留既有玻璃效果。
- 「按鍵透明度」調整原生玻璃的染色與表面填色濃度，玻璃視圖本身維持 alpha = 1。
- 系統底板、地球／麥克風區域仍由 iOS 管理；這次不會移除它們。

## 真機檢查

1. 選圓角＋液態玻璃，分別用有照片／無照片、淺色／深色主題試打。應看到原生材質，沒有舊版的大白光點或雙重亮邊；文字與功能鍵顏色仍清楚。
2. 切換圓角、果凍、貓掌，再切換平面、金屬、液態玻璃。檢查造型輪廓完整，切回時沒有殘留玻璃、空白按鍵或消失的陰影。
3. 在高度、間距、字體大小及透明度的兩端值試打；橫豎向切換後，玻璃應對齊每顆鍵。按鍵動畫選「無」時是輕微縮放；其他動畫仍依照使用者選項。
4. 連續輸入注音與英文、切換數字頁，測試多指連打、滑行輸入、長按刪除、標點選單。比較原版打字流暢度與記憶體峰值，不能因材質增加而閃退。
5. 按住空白鍵拖曳游標後放開，按鍵材質與文字應恢復；拖曳中不應有黑塊或殘影。
6. 開啟照片位置調整，拖拉、縮放、重設後完成。調整中暫時隱藏原生玻璃並淡化文字，完成後恢復材質與按鍵輸入。
7. 檢查工具列、組字候選列和編輯列切換，候選字可以橫向捲動、點選，工具按鈕與高度拖曳區仍能操作。
8. 開啟「減少動態效果」確認原生玻璃按鍵不做縮放；開啟「降低透明度」確認系統材質與文字對比可用。在舊版 iOS 重做造型／質感切換與游標拖曳，確認替代效果正常。

## 實作約束

`KeyboardGlassSurface` 集中處理 SDK／系統版本檢查、主題染色與圓角。它是非互動背景，輸入仍由 `KeyboardGridView` 處理。按壓只改前景填色和既有動畫，不在每次觸碰時重建玻璃效果。

原生玻璃不能放入帶遮罩的父視圖，也不能把其父層 rasterize 或整體調低 alpha。游標模式和照片調整因此改成分別淡化前景與暫時隱藏原生材質。

參考：[Apple UIVisualEffectView 的 alpha／遮罩限制](https://developer.apple.com/documentation/uikit/uivisualeffectview)、[UIGlassEffect](https://developer.apple.com/documentation/uikit/uiglasseffect)、[圓角設定](https://developer.apple.com/documentation/uikit/uicornerconfiguration-swift.struct)。

本次開發環境為 Linux，沒有 Xcode／UIKit SDK；本機只能檢查差異與 workflow YAML，尚未完成 iOS 編譯、真機外觀或效能驗證。打包 workflow 已指定 Xcode 26.3，需由使用者推送後進行編譯與安裝驗證。
